# 🛒 গ্যাজেট বাজার — Gadget Bazar

> বাংলাদেশের ইলেকট্রনিক গ্যাজেটের **সম্পূর্ণ বাংলা**, মোবাইল-ফার্স্ট, ফুল-স্ট্যাক ই-কমার্স ওয়েবসাইট।
> Next.js + TypeScript + Tailwind CSS | Vercel-এ **এক ক্লিকে, কোনো এনভায়রনমেন্ট ভ্যারিয়েবল ছাড়াই** ডিপ্লয়যোগ্য।

A fully-Bangla, mobile-first, full-stack e-commerce website for an electronics/gadget shop in Bangladesh. Built with Next.js (App Router), TypeScript and Tailwind CSS. Deploys to Vercel straight from this repository with **zero configuration**.

---

## 🚀 Vercel-এ ডিপ্লয় (সবচেয়ে সহজ পথ)

1. এই রিপোজিটরিটি আপনার GitHub অ্যাকাউন্টে আছেই।
2. [vercel.com](https://vercel.com) → **Add New… → Project** → রিপোজিটরিটি **Import** করুন।
3. Framework স্বয়ংক্রিয়ভাবে **Next.js** ডিটেক্ট হবে। **কোনো Environment Variable দিতে হবে না।**
4. **Deploy** চাপুন। ব্যাস! 🎉

> **কোনো এরর আসবে না**, কারণ:
> - কোনো বিল্ড-টাইম নেটওয়ার্ক কল নেই (ফন্ট ও ছবি সম্পূর্ণ সেল্ফ-হোস্টেড)
> - ESLint বিল্ডে বন্ধ (`eslint.ignoreDuringBuilds`), টাইপ-চেক পরিষ্কার
> - ডাটাবেস ঐচ্ছিক — env না দিলে ইন-মেমরি মোডে চলে
> - কোনো এক্সটার্নাল সার্ভিস/পেমেন্ট গেটওয়ের উপর নির্ভরতা নেই

### ডিপ্লয়ের পর যা করবেন
1. `https://your-app.vercel.app/admin` → লগইন: `admin@gadgetbazar.com` / `admin123`
2. **সেটিংস** → আপনার আসল **হোয়াটসঅ্যাপ নম্বর** দিন (ফরম্যাট: `8801XXXXXXXXX`)।
3. অ্যাকাউন্ট পেজ থেকে **পাসওয়ার্ড বদলে নিন**।

## 🗄️ স্থায়ী ডাটাবেস (ঐচ্ছিক, ফ্রি)

ডিফল্টে সাইট **ইন-মেমরি (ডেমো)** স্টোরেজে চলে — সার্ভার রিস্টার্টে ডেটা রিসেট হয়। অর্ডার/পণ্য/অ্যাকাউন্ট স্থায়ী রাখতে একটি ফ্রি Postgres যুক্ত করুন — **কোডে কোনো পরিবর্তন লাগবে না**:

1. [neon.tech](https://neon.tech) (বা Supabase) → ফ্রি প্রজেক্ট খুলুন → connection string কপি করুন।
2. Vercel → Project → **Settings → Environment Variables** → যোগ করুন:
   - `DATABASE_URL` = `postgresql://user:pass@host:5432/dbname?sslmode=require`
3. **Deployments → Redeploy** করুন। টেবিল ও সিড ডেটা স্বয়ংক্রিয়ভাবে তৈরি হবে।

অন্যান্য ঐচ্ছিক ভ্যারিয়েবল দেখুন [`.env.example`](./.env.example)।

| ভ্যারিয়েবল | কাজ | ডিফল্ট |
|---|---|---|
| `DATABASE_URL` | Postgres connection string | — (ইন-মেমরি) |
| `AUTH_SECRET` | JWT সেশন সিক্রেট | ডেভ ফলব্যাক |
| `NEXT_PUBLIC_WHATSAPP_NUMBER` | হোয়াটসঅ্যাপ অর্ডার নম্বর | অ্যাডমিন সেটিংস |
| `NEXT_PUBLIC_SITE_URL` | ক্যানোনিক্যাল URL (SEO) | — |

## 🧱 টেক স্ট্যাক ও গঠন

- **Framework:** Next.js 15 (App Router) + React 19 + TypeScript
- **স্টাইল:** Tailwind CSS 3 (কাস্টম বাংলা-ফ্রেন্ডলি ডিজাইন সিস্টেম)
- **ফন্ট:** Anek Bangla (ভ্যারিয়েবল) + Hind Siliguri — সম্পূর্ণ সেল্ফ-হোস্টেড
- **অথ:** JWT (httpOnly কুকি) + WebCrypto PBKDF2 পাসওয়ার্ড হ্যাশ — কোনো এক্সটার্নাল অথ সার্ভিস নেই
- **ডাটা:** প্লাগেবল স্টোর — `memory` (ডিফল্ট) / `postgres` (`@neondatabase/serverless`)
- **আইকন:** lucide-react | **ছবি:** AI-জেনারেটেড প্রোডাক্ট শট (`public/products/`)

```
app/            # পেজ ও API রুট (App Router)
  api/          # auth, orders, products, admin/* REST এন্ডপয়েন্ট
components/     # UI কম্পোনেন্ট + admin শেল
lib/            # config, auth, bangla ফরম্যাটিং, whatsapp, store (memory/postgres)
public/         # ছবি, ফন্ট, আইকন, ম্যানিফেস্ট
```

## 📲 হোয়াটসঅ্যাপ অর্ডার ফ্লো

1. কাস্টমার কার্টে পণ্য যোগ করে **ভাসমান সবুজ হোয়াটসঅ্যাপ বাটনে** ক্লিক করে → সম্পূর্ণ অর্ডার-মেসেজ (পণ্য, পরিমাণ, মোট, ডেলিভারি) সরাসরি অ্যাডমিনের হোয়াটসঅ্যাপে খুলে যায়।
2. অথবা চেকআউট ফর্ম পূরণ → অর্ডার ডাটাবেসে সংরক্ষিত হয় → সাকসেস পেজ থেকে **গ্রাহকের তথ্যসহ** মেসেজ পাঠানো যায়।
3. অ্যাডমিন প্যানেল থেকে অর্ডারের স্ট্যাটাস (`অপেক্ষমাণ → নিশ্চিত → পাঠানো → ডেলিভারি`) আপডেট করেন।
4. পেমেন্ট সবসময় **ক্যাশ অন ডেলিভারি**।
